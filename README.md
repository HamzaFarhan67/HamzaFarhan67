## 🚀 Featured Projects

### 🤖 [FinanceAnalysis — Multi-Agent Financial AI](https://github.com/HamzaFarhan67/FinanceAnalysis)
A multi-agent AI system that ingests transaction data, tracks budgets, produces conversational financial summaries, and automatically renders visualizations.

`Python 3.11` `FastAPI` `FastMCP` `Pydantic AI` `SQLAlchemy` `PostgreSQL` `pgvector` `React`

- Automated agent orchestration (transaction, budget, forecast, summarizer, visualization subagents).
- RAG utilities for chunking, vector embeddings, and retrieval using PostgreSQL + pgvector.
- Automatic DataFrame summarization and chart rendering pipeline (ChartSpec → matplotlib PNG).

### 🍲 [PantryToPlate — Agentic AI Culinary Platform](https://github.com/HamzaFarhan67/PantryToPlate)
An AI-powered cooking assistant that tracks pantry ingredients and features a conversational "Chef Coach" chatbot for real-time, step-by-step guidance.

`React` `Tailwind CSS` `Firebase` `FastAPI` `LangChain` `Google Gemini` `Pydantic`

- Real-time pantry tracking with Firebase authentication and Firestore sync.
- AI recipe matching and conversational sous-chef for live substitutions and instructions.
- Structured output schema enforcement via Pydantic for stateful cooking instructions.

### 🥊 Motion Brawl & CV Controller — RL Boss AI & Vision Input System
[Game Repo](https://github.com/HamzaFarhan67/MotionBrawl) · [CV Controller Repo](https://github.com/HamzaFarhan67/CV_Gesture_Detection) — two linked repos that work together.

An integrated fighting game system: a computer-vision gesture controller translates webcam input into game actions over UDP, driving combat against an adaptive, RL-trained boss.

`Python` `OpenCV` `MediaPipe` `TensorFlow Lite` `Gymnasium` `Stable-Baselines3` `SFML` `UDP Sockets`

- Real-time gesture detection mapping hand/body tracking to combat actions (JUMP, ATTACK, SHIELD) over UDP.
- Custom RL environment using Gymnasium and PPO (Stable-Baselines3) with reward shaping for boss strategies.
- SFML interface with dynamic HUD, health bars, and PvP player-zone support.
